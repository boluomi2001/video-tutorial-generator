# 视频 → 教学教程生成器

## 一、触发方式

用户说以下任一表达时自动触发本 Skill：

| 触发词 | 含义 |
|--------|------|
| 「分析视频」/「跑流水线」/「视频转笔记」 | 启动视频解析流水线 |
| 「视频转教程」/「生成教程」 | 解析后直接输出教程 |
| 「展开为复刻教程」/「生成复刻教程」 | 明确要求输出**项目复刻教程** |
| 「展开为功能教程」/「生成效率提升教程」 | 明确要求输出**功能提升教学** |
| 提供视频链接 + 上述任一关键词 | 自动下载并解析 |

触发时若用户同时给了视频链接，则从链接开始；若只给 run_id（如 `20260715_143548`），则跳过解析直接出教程。

---

## 二、输入参数

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `video_source` | 是 | 视频链接 / 本地文件路径 / run_id | `https://...`、`downloads/xx.mp4`、`20260715_143548` |
| `output_type` | 否 | 教程类型，缺省自动判定 | `复刻` / `功能` |
| `style` | 否 | 教程深度，缺省为「详细」 | `详细` / `精简` |

**约束条件（重要）：**
1. 视频文件须能被下载或已存在于 `tools/weixin-favor-kb/downloads/`。
2. Whisper 转录是 CPU 密集操作，35 分钟视频约需 20-30 分钟，**无法在后台任务中完成**（平台约 10 分钟超时），必须通过 `.cmd` 脚本在独立进程运行。
3. 仅支持有语音讲解的视频；纯音乐/无语音视频只能做画面分析，无法生成完整教程。
4. 语言默认中文（Whisper `language=zh`）。

---

## 三、执行步骤

### 阶段 0：获取视频

根据 `video_source` 类型决定：

- **微信视频号链接/收藏** → 用 `tools/wx_channel/wx_channel.exe` 下载到 `downloads/`。
- **直链 mp4** → `curl -L -o downloads/<name>.mp4 <url>`。
- **本地文件路径** → 确认存在，必要时复制到 `downloads/`。
- **run_id** → 跳过本阶段和阶段 1、2，直接进入阶段 3。

### 阶段 1：语音转录（慢，需独立进程）

调用 `tools/weixin-favor-kb/step1_transcribe.cmd`，或让用户双击该脚本：

```
step1_transcribe.cmd [视频路径或文件名]
```

产出（存放在隔离目录 `output/<时间戳>_<视频名>/`）：
- `transcripts/<视频名>.txt` — 完整转录文字
- `transcripts/<视频名>_segments.json` — 带时间戳的分段数据
- `audio.wav` — 提取的音频

### 阶段 2：视觉分析（快，2-3 分钟）

调用 `tools/weixin-favor-kb/step2_analyze.cmd <run_id>`：

```
step2_analyze.cmd <阶段1输出的 run_id>
```

产出：
- `frames/` — 关键帧图片
- `notes/<视频名>.md` — 结构化 Obsidian 笔记（含摘要、画面观察、核心要点、资源、建议、时间轴分段）

### 阶段 3：判定视频类型

读完整转录 + 画面观察 + 关键要点，判定为二选一：

| 类型 | 特征 | 输出 |
|------|------|------|
| **项目分享教学** | 涉及完整项目搭建/复刻/实现（小程序、网站、AI 工具接入、自动化系统搭建等），读者需"打造自己的版本" | **项目复刻教程** |
| **功能类知识分享** | 涉及工具使用/技能分享/效率提升技巧（Prompt 技巧、软件使用、工作流方法等），读者"直接学方法" | **效率提升教学** |

判定依据优先级：**视频的核心目标是什么**——是"教你做一个东西"（→ 复刻），还是"教你会用一个东西/一种方法"（→ 功能）。

### 阶段 4：生成教程

按判定类型套用对应模板（见 `references/tutorial-templates.md`），生成完整教程并保存。

## 四、输出格式

### 4.1 通用结构（两种教程共用）

```
---
title / author / date / category / tags / source
---

# 标题

> 视频类型标注 + 核心价值一句话

## 案例/背景概述（可选，项目教程需拆解示例项目）

## 知识点一 … 知识点 N（每个知识点固定含 5 要素）
  1. 详细操作步骤（逐步）
  2. 关键注意事项
  3. 常见问题及解决方案（FAQ 表）
  4. 参数配置说明（表格：参数/默认值/调整建议）
  5. 原理简述（为什么这样做）

## 完整工作流总结（流程图）

## 资源与工具 / 竞品对比（视类型而定）
```

### 4.2 项目复刻教程 —— 特有内容

- **项目概述**：项目是什么、技术栈、架构图
- **环境搭建**：需安装的软件、版本要求、配置步骤
- **逐模块实现**：从零到一的完整实现步骤（含代码结构/关键逻辑）
- **测试调试**：测试清单、调试工具、常见报错
- **部署上线**：发布流程、平台配置、审核要点
- **个性化定制**：如何把示例替换成自己的主题

### 4.3 效率提升教学 —— 特有内容

- **工具/方法概览**：解决什么痛点、核心价值
- **安装/上手**：安装步骤、兼容性说明
- **核心操作**：详细使用步骤、提示词模板
- **进阶技巧**：优化方法、成本分析
- **竞品对比**：与同类工具的差异

两种模板的完整结构见 `references/tutorial-templates.md`。

## 五、输出落盘规则

| 视频类型 | 输出目录 | 文件命名 |
|----------|----------|----------|
| 项目教学 | `outputs/公众号视频项目/项目复刻教学/` | `<主题>_复刻教程.md` |
| 功能教学 | `outputs/公众号视频项目/功能提升教学/` | `<主题>_效率提升教学.md` |

同时保留一份在 `outputs/` 根目录便于快速查看。

## 六、技术栈与路径

| 组件 | 位置 |
|------|------|
| 转录 | faster-whisper small/medium，本地模型 `tools/weixin-favor-kb/models/whisper-{small,medium}/` |
| OCR | RapidOCR (onnxruntime) |
| 视觉分析 | Qwen3-VL-32B-Instruct @ 硅基流动，`tools/weixin-favor-kb/config.yaml` |
| 音频提取 | ffmpeg 8.1.2 |
| 视频下载 | wx_channel.exe（微信视频号）/ curl / yt-dlp |
| 笔记模板 | Jinja2，`tools/weixin-favor-kb/templates/obsidian.md` |

**Windows 关键约束：**
- 需设置 `PYTHONIOENCODING=utf-8` + `PYTHONLEGACYWINDOWSSTDIO=utf-8`（否则 GBK 报错/emoji 崩溃）。
- `cv2.imwrite` 不支持中文路径，关键帧保存用 `np.fromfile` 绕过。
- 文件名含 `# ! ?` 等字符时须先清理（`sanitize`）再创建目录。

## 七、常见执行边界

- 若视频只有链接但下载失败 → 明确告知用户，请求提供本地文件或换链接。
- 若转录阶段未跑（无 `_segments.json`）→ 先引导运行 step1，再继续。
- 若用户只要「分析笔记」而非教程 → 阶段 2 的 Obsidian 笔记即为交付物，跳过阶段 3-4。
- 生成教程前若需确认类型 → 可向用户说明判定结果并询问是否调整。
