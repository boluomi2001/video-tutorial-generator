三类：

1. [给 Agent 的安装提示词](#a-安装类)
2. [日常使用提示词](#b-日常使用类)
3. [调参与排错提示词](#c-调参排错类)

## A. 安装类

### A1. 让 Agent 全权安装（最省事）

```
这是「视频 → 教学笔记」工作流的安装包，请帮我装好并按下来验证。

约束条件：
- 先看 README.md 第 3 节，严格按顺序执行 Step 0 ~ Step 6
- Python 必须是 3.10~3.12，检测到 3.13 就停下来告诉我
- pip 走清华源：-i https://pypi.tuna.tsinghua.edu.cn/simple
- ffmpeg 没装就用 winget install Gyan.FFmpeg
- API Key 我从环境变量 LLM_API_KEY 提供，不要回显、不要写入聊天记录以外的文件

每一步做完后报告：做了什么 / 结果如何 / 下一步是什么。
失败时把原始报错完整贴给我，不要自己猜原因也不要静默重试。
```

### A2. 只让 Agent 做环境体检

```
检查这套视频解析工作流的运行环境是否就绪，只检查不修改：

1. Python 版本（要求 3.10~3.12）
2. tools\weixin-favor-kb\venv 是否存在，依赖是否完整
3. ffmpeg 是否可用
4. tools\weixin-favor-kb\config.yaml 是否存在、api_key 是否还是占位符
5. tools\wx_channels_download\config.yaml 是否存在、mcp 是否 enabled
6. 2022 端口是否在监听

用表格输出：检查项 / 结果 / 不通过时的修复命令。
```

### A3. 让 Agent 接入 Agent 客户端

```
把这套工作流接进我的 Agent：

1. 把 skill\video-analyzer\ 复制到我的技能目录
   （WorkBuddy 是 C:\Users\<用户名>\.workbuddy\skills\video-analyzer\）
2. 在我的 MCP 配置里加上 wx_channels_download：
   {"mcpServers":{"wx_channels_download":{"type":"streamable-http","url":"http://127.0.0.1:2022/mcp"}}}
3. 把 scripts\start_downloader.vbs 的快捷方式放进 shell:startup 实现开机自启
4. 完成后用一个本地视频文件跑通验证，把生成的笔记速览给我看
```

## B. 日常使用类

### B1. 要完整教程

```
分析这个视频：<粘贴链接>
```

Skill 会接管，无需多说。想显式一点：

```
请把 <链接> 这个视频完整分析，输出详细教程。要求：
- 每个知识点都要有可执行的操作步骤
- 关键命令要能直接复制运行
- 附上参数说明和我可能会踩的坑
```

### B2. 只想要速览

```
这个视频讲了什么？给我速览就够了：<链接>
```

### B3. 只想要可执行清单

```
把它展开成我能照着做的清单，每步配命令：<链接>
```

### B4. 指定输出类型

```
按「项目复刻教程」的方式展开这个视频，我需要能复刻出一个自己的版本：<链接>
```

```
这是功能类知识分享，请按「效率提升教学」输出，不要写成项目搭建教程：<链接>
```

### B5. 处理本地文件

```
分析这个本地视频：D:\videos\我的录屏.mp4
```

### B6. 批量处理

```
依次分析下面几个链接。每处理完一个，先给我它的速览，我确认后再处理下一个：
1. <链接1>
2. <链接2>
3. <链接3>
```

### B7. 中途问进度

```
现在跑到哪一步了？
```

### B8. 失败重来

```
上一次失败了，视频应该还在 downloads 目录里，请直接用本地文件重试一次，
重试前先告诉我上一轮失败的原因。
```

## C. 调参排错类

### C1. 笔记太粗

```
这份笔记内容太粗了，请重跑并优化：
- 视觉模型换成 Qwen/Qwen3-VL-32B-Instruct（慢一点没关系）
- 抽帧数量翻倍
- 章节切得更细，每个章节都要独立成文
```

### C2. 转录为空

```
这个视频转录出来是空的，应该是没有旁白。请基于画面 OCR 和关键帧重写笔记，
如果画面信息也不足，明确告诉我这个视频不适合自动提取。
```

### C3. 批量前先算成本

```
我有 50 个视频要处理，先估算一下时间和 API 花费，
并告诉我哪几个参数能降低成本、降了之后质量会损失多少。
```

### C4. 报错求助模板

```
跑挂了，报错如下：

<粘贴完整报错>

环境：
- Python 版本：
- 操作系统：
- 视频时长 / 大小：
- 是在哪一步失败的（看 progress.json 的 stage 字段）：

请直接给修复方案，不要泛泛而谈。
```

## 提示词写作小贴士

| 技巧 | 说明 |
|---|---|
| 链接放最后 | Agent 更容易把整句识别成"分析这个视频"意图 |
| 说清输出形态 | 教程 / 速览 / 清单，三种产物质量差异很大 |
| 失败贴原文报错 | 比描述"好像报错了"有用十倍 |
| 指定对象读者 | 例如"写给完全没接触过 Python 的人"，笔记会明显更好读 |
